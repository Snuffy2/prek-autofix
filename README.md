# prek-autofix

`prek-autofix` is a planned GitHub Action for running
[`prek`](https://github.com/j178/prek) on pull requests and safely committing
automatic fixes back to the existing pull request branch.

The project is currently in the design stage. See the
[implementation plan](docs/implementation-plan.md) for the proposed security
model, public interface, documentation requirements, and test strategy.
